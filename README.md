# Stack_
>light-weight to-do application written on neutralino.js, I think it uses 80mb of RAM?
> still improving the performance and other stuff.

## How to use it?
> literally just download the `resources.neu' and 'stack.exe', drop both on a same folder and just run the .exe file.
> you may encounter a prompt when launching the .exe during your first run, but that's just a false warning due to the app is unsigned.
